# Add a tooltip icon to a label

Add a tooltip icon to a label

## Usage

``` r
add_tooltip_icon(..., id, icon = shiny::icon("info-circle"))
```

## Arguments

- ...:

  Arguments passed to span element (e.g., the label to add the tooltip
  to).

- id:

  The id of the tooltip.

- icon:

  The icon to use for the tooltip.

## Value

The label with the tooltip icon.
