# Get html snippet for built-in icons.

Get html snippet for built-in icons.

## Usage

``` r
get_icon(src, width = 20, height = 20, ...)
```

## Arguments

- src:

  Name of built-in icon.

- width:

  Width of icon in pixels.

- height:

  Height of icon in pixels.

- ...:

  Additional arguments to pass to
  [`htmltools::img()`](https://rstudio.github.io/htmltools/reference/builder.html).

## Value

Character vector of icon path.
