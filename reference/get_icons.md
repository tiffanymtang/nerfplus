# Return custom icons

Return custom icons

## Usage

``` r
get_icons(icon_names, width = 20, height = 20, ...)
```

## Arguments

- icon_names:

  Name(s) of built-in icons to return.

- width:

  Width of icon in pixels.

- height:

  Height of icon in pixels.

- ...:

  Additional arguments to pass to
  [`htmltools::img()`](https://rstudio.github.io/htmltools/reference/builder.html).

## Value

Named character vector of html snippets to display icons
